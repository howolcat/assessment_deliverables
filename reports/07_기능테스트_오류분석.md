## 4. 오류 이력

| 오류 ID | 현상 | 원인 확인 | 조치 | 재검증 | 결과 |
|---|---|---|---|---|---|
| E-01 | job 5가 `queued`에서 진행되지 않음 | Celery worker 정지 (T-10에서 **의도적으로 재현**) | `docker compose start worker` | 약 10초 후 같은 `job_id` 재조회 | `done` (healthy 0.7499). 재시작 직후 조회는 아직 `queued` — worker 준비 시간 필요 |
| E-02 | 문서 명령 `docker compose exec web pytest -q tests/test_api.py` 실행 시 `ModuleNotFoundError: No module named 'ai'` | `pytest` 명령은 작업 폴더(`/app`)를 모듈 경로에 넣지 않음. `tests/`에 `__init__.py`가 없어 `/app/tests`만 경로에 추가됨 | **코드 수정 없이** `python -m pytest`로 실행 방식만 변경 (`python -m`은 현재 폴더를 경로에 추가) | 같은 테스트 재실행 | **4 passed** |
| E-03 | 비동기 접수가 503 반환 | Redis 정지로 브로커 연결 실패 (T-12에서 **의도적으로 재현**) | `docker compose start redis` | worker 로그와 새 작업 확인 | worker가 자동 재연결 (`Trying again in 8.00 seconds... (4/100)` → `Connected`), job 17 `done` |
| E-04 | 01 단계에서 `bad.txt` 테스트 시 `curl: (7) Failed to connect` | pytest 실행을 위해 로컬 uvicorn을 종료한 상태에서 요청 | 터미널을 나눠 서버를 켠 채로 요청 | 같은 요청 재실행 | 400 정상 응답 |

증빙: [pytest_import_error.png](evidence/pytest_import_error.png) · [server_down.png](evidence/server_down.png) · [worker_start_immediate_queued.png](evidence/worker_start_immediate_queued.png)

## 5. 관찰된 경고 (동작에 영향 없음, 제공 코드 그대로 유지)

| 경고 | 위치 | 의미 | 조치 |
|---|---|---|---|
| `SecurityWarning: You're running the worker with superuser privileges` | worker 시작 로그 | 컨테이너 안에서 root로 Celery 실행 | 실습 환경이라 유지. 운영 시 `--uid` 지정 또는 비root 사용자 권장 |
| `Using a slow image processor as use_fast is unset` | worker 첫 추론 | transformers의 이미지 전처리기 버전 안내 | 결과 영향 없음, 유지 |
| `StarletteDeprecationWarning: Using httpx with starlette.testclient is deprecated` | pytest | 테스트 클라이언트 라이브러리 안내 | 결과 영향 없음, 유지 |

## 6. 데이터·환경 관련 기록
